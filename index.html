How processing works

The prompt-free MobileSAM model includes ImageNet normalization and logit upsampling. Tiles follow the linked Python reference: EXIF orientation, centered black padding for small images, edge-aligned final tiles, and later tiles replacing overlap. Logits ≥ 0 identify roots. FP32 is used on both backends for consistency.

CPU uses one WebAssembly thread for compatibility with GitHub Pages. WebGPU requires a working browser GPU adapter; unsupported operators may run through WASM. The app never silently changes your selected backend. Completed masks use one bit per pixel; only one image is decoded at a time. Previews are created only when requested outside processing.
